File Integrity Monitor

A Python script that saves or compares SHA-256 hash records for a specified directory.

Works in two primary modes:

"--init": Saves the current state of a directory for later comparison,

"--check" : Compares a previously saved state with the current directory contents.

Additional arguments allow you to custom-define target, state, and log file paths.
